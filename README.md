## 🧩 Sobre este repositorio
Este repositorio centraliza los ejercicios y miniproyectos realizados durante el bootcamp. Cada carpeta contiene un proyecto independiente con su propio `index.html`, carpeta `css/` y `js/` cuando corresponde.

---

## 🗂️ Estructura real del repo
A partir de la raíz del repositorio (`/`), estas son las carpetas presentes actualmente:

- `barra-navegacion/`  
- `evento-onclick/`  
- `gamesteam-flex/`  
- `me-gusta/`  
- `pagina-perfil-yuna/`  
- `yootuve-vista-previa-video/`

---

## 🔥 Proyectos destacados (resumen rápido)

### 🔹 `barra-navegacion`  
Componentes y ejemplos de barras de navegación: responsive, dropdowns y efectos al hacer scroll.

### 🔹 `evento-onclick`  
Ejercicios centrados en manejo de eventos `click` y manipulación del DOM.

### 🔹 `gamesteam-flex`  
Maquetación tipo grid/flex para una sección estilo “tienda” o listados.

### 🔹 `me-gusta`  
Interacción tipo “like” (contador, toggles, animaciones) para practicar estados y eventos.

### 🔹 `pagina-perfil-yuna`  
Maquetación de una página de perfil con información y diseño responsive.

### 🔹 `yootuve-vista-previa-video`  
Proyecto donde al seleccionar un video lateral se actualiza el reproductor principal — ideal para practicar eventos, dataset de videos y DOM dinámico.

- Dominar maquetación y semántica HTML

- Aprender flujo de trabajo con GitHub
